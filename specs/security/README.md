# Security documentation

Reserved for threat models, security review notes, and hardening checklists.
It is currently a placeholder: no threat model has been written yet, and that
gap is real rather than an omission from this index.

Vulnerability disclosure is not here — it is `SECURITY.md` at the repository
root. The user-facing description of isolation, roles, credential handling, and
content safety is `docs/concepts/security-model.md`, published on the
documentation site.

Security-sensitive changes remain traceable to the blueprint invariants,
especially cross-account isolation, user-owned data and keys, governance gates,
auditability, and deployment-mode parity.
