# Lite profile spike results (PROF-04, PROF-06, PROF-07)

Generated by `crates/memhouse-bench/examples/spike_lite_profile.rs` on 1 November 2026 on the reference laptop (Apple Silicon, other heavy processes running). The store is built once (`build`), then each run is a **fresh process** (`run`, `run --no-model`). Every step ran under `sandbox-exec` with **all networking denied** (`(deny network*)`; a test `curl` to the model hub failed to resolve), so the candidate needs no external service or network: SQLite is compiled in, the job queue and worker are in process, and the model is read from the local cache.

Reproduce:

```bash
X=target/release/examples/spike_lite_profile   # built with --features spike
sandbox-exec -p "(version 1) (allow default) (deny network*)" $X build
sandbox-exec -p "(version 1) (allow default) (deny network*)" $X run
SPIKE_SESSIONS=1 sandbox-exec -p "(version 1) (allow default) (deny network*)" $X run
sandbox-exec -p "(version 1) (allow default) (deny network*)" $X run --no-model
```

## Thread-count check (option b of ADR 0002)

One model session, networking denied, same store:

| Threads per session | Recall p95 | Peak resident memory |
|---|---|---|
| 1 | 45.9 ms | 384 MB (158 MB after loading the model, 325 MB after the recall run) |
| 2 | 27.7 ms | 379 MB (158 MB after loading the model, 321 MB after the recall run) |

Fewer threads don't reduce memory and cost latency. The growth after loading happens inside the
inference runtime's allocations; reducing it needs session-level settings that the embedding
library doesn't expose today, so option (b) is work for G16, not a configuration change.

## Reading

- **PROF-07 is met in every configuration**: recall p95 26–29 ms with the local model (14 ms store only) at 10,000 memories per subject; durable acknowledgement p95 3.3 ms even with power-loss-safe `fullfsync`; a written memory is recallable in 23–26 ms p95.
- **PROF-06 is met by the store** (16 MB peak with 100,000 memories) **but not with the bundled local model**: the model adds 157 MB per session at load and the inference runtime grows to a 394 MB peak with one session (610 MB with the default four). The 256 MB budget can only hold with a remote embedding endpoint, or with a smaller footprint for the local model — a decision for G16 (see ADR 0002).
- **PROF-04 shape holds**: one process, no external service, no network.
