# Issue tracker

Use GitHub for repository issues and pull requests.

- Canonical project remote: `memhouse` (`memhousehq/memhouse`).
- Checkout remote: `origin` (`cartularyhq/cartulary`).
- Link implementation work to one GitHub issue and one pull request.
- Follow the one-task, one-branch, one-PR workflow in `CONTRIBUTING.md`.
- Treat `ai-ready` as the required execution-control label for agent work.

Do not infer repository settings, branch protection, required checks, or label
state from workflow files. Verify GitHub-side state when the task depends on it.
